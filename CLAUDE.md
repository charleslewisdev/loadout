# Working on loadout in public

This repository is public. Anything posted to GitHub from it is a publication.

- Write an issue, PR body or comment to a file, run `GUARD_REQUIRE_DENYLIST=1 guard/scan text FILE`, show the owner, then post with `--body-file`. `guard/gh-hook` blocks gh commands that skip this.
- An issue describes the fix, never the leaked text. Private findings stay in `.private/`, which git ignores.
- History rewrites and edits to old PR bodies are the owner's call: list them, don't apply them.
- Theme: names, headings and ceremonial output (status, retro, papercut) may wear the Crystal Bridge RPG flavor. The plain fact, command or number always stays beside it.
