# Lens: portfolio

Compare this repo with recent work in the owner's other repos, listed in `portfolio.txt` in the facts directory.

Answer these for this repo:

- Did another repo already solve a problem this one still has?
- Did this repo solve something worth carrying to another?
- Could the two integrate?

Report a hit only when a name, description, map entry or recent commit ties it to something you found in this repo. A shared language or framework isn't a hit. Give the other repo, the direction of the borrowing, and why. If the file says the portfolio is off or unavailable, say so. No hits is a normal result.

These aren't defects, so use severity Consider.
