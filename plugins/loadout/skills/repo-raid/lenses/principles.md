# Lens: principles

Check the repository against its own rules and the owner's conventions.

- Read the repo's `CLAUDE.md`, `AGENTS.md`, `CONTRIBUTING.md` and `.claude/rules/`, and `conventions.md` in the facts directory if it's there.
- For each rule the code can break, look for where it does. Name the rule's file and line, and the code that breaks it.
- `log.txt` holds recent commits: check commit style only if a rule sets one.
- A rule in `conventions.md` that concerns the owner's machine or session doesn't apply to the repo. Skip it.

Report a broken rule the repo or the owner states. Skip taste, and skip rules no code can break.
